# 🌐 Personal Portfolio Website - Veros Ariferdinand

Website ini adalah **website statis perkenalan/portfolio** yang menampilkan informasi singkat tentang saya, project/portofolio, serta kontak untuk dihubungi.  
Dibuat menggunakan **HTML5, CSS3, dan Bootstrap 5**, dengan tambahan library animasi dan ikon modern.

---

## ✨ Fitur
- **Sidebar Navigasi**  
  - Tentang Saya  
  - Portofolio  
  - Kontak  

- **Profil Singkat** dengan foto dan deskripsi.  
- **Link Sosial Media**: WhatsApp, GitHub, Instagram.  
- **Desain Responsif** (mobile friendly).  
- **Animasi Ringan** dengan library `animate.css` dan `swiper.js`.

---

## 🚀 Teknologi yang Digunakan
- [Bootstrap 5](https://getbootstrap.com/)  
- [Font Awesome 6](https://fontawesome.com/)  
- [Animate.css](https://animate.style/)  
- [Swiper.js](https://swiperjs.com/)  
- [Magnific Popup](https://dimsemenov.com/plugins/magnific-popup/)  
- Custom CSS & JavaScript  

---

## 📂 Struktur Utama
```
index.html        # Halaman utama website
cv_files/         # Folder berisi asset (CSS, JS, gambar)
```

## 🔧 Cara Menjalankan
1. Clone repository ini:
   ```bash
   git clone Verosariferdinand/Verosariferdinand.git
   ```
2. Buka file `index.html` di browser.  
   Tidak perlu server tambahan karena ini website statis.
